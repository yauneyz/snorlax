We are going to build an app for Android, specifically the Pixel 8 Pro and Pixel 10 Pro XL. In cases where capabilities differ, we will default to the more capable with a fallback for the less capable.

We want to be able to do the following things:

- speech recognition, tts, and LLM responses will all be handled by a server.
- config and security will be handled by a file that gets shipped with the app (which only I will have the apk for, I won't post it online). This file tells the app both what url to use and also give it an auth token, so that I can securely expose the endpoint to the internet for remote use

- the app sends audio to the backend, the backend processes it and sends it back as speech.
- A file detailing the backend we are a client of:
  <insert filename here>

- a WearOS app that connects and functions as the "remote control" so that we don't have to touch our phone to use the app.
  - pairs to the phone app somehow
  - long presses are push-to-talk
  - short taps turn recording on/off
  - the entire watchface is the touch target when this is active, so that we can touch it without looking at the screen
  - the watch can interface with the app even with the phone locked and in the pocket


- we want to be able to upload PDFs of recipes and have the llm walk the user through cooking with the recipe.
